## 2. 模块结构

```
app/src/main/java/com/highlightrecorder/upload/
├─ BaseUrlValidator.kt          # https+公网地址校验（纯 JVM）
├─ CredentialProvider.kt        # 认证抽象 + 开发期静态令牌实现（纯 JVM）
├─ ChunkSource.kt               # 分片数据源抽象 + MediaStore/file 双兼容实现 + SHA-256
├─ ErrorPolicy.kt               # 重试处置决定 + 退避策略（纯 JVM）
├─ UploadSettings.kt            # 上传配置（独立 DataStore）
├─ UploadTaskRepository.kt      # 任务状态迁移集中地
├─ UploadWorker.kt              # 前台上传执行器（编排:哈希→协议→状态回写）
├─ UploadScheduler.kt           # WorkManager 唯一队列
├─ UploadCoordinator.kt         # 保存成功挂接点 + 启动恢复
├─ Deps.kt                      # 进程级单例
├─ db/UploadTaskDb.kt           # Room 实体/DAO/DB
└─ protocol/
   ├─ CloudreveProtocol.kt      # ⚠️ 端点与字段集中定义（TO_VERIFY,联调只改此文件）
   └─ CloudreveV4Uploader.kt    # 三步协议客户端（纯 JVM,可 MockWebServer 单测）
```

接入点改动（最小化，均不影响原录制功能）：`RecordingService.saveClip()` 保存成功后调用协调器；`HighlightApp.onCreate()` 恢复队列；Manifest 增 `INTERNET / ACCESS_NETWORK_STATE / FOREGROUND_SERVICE_DATA_SYNC` 与 SystemForegroundService `dataSync` 合并声明。
