## 3. 过程中发现的事项

1. **悬浮球功能正常**：首轮排查时误判其无效，实为检查命令输出被截断；悬浮球单击保存已验证成功。
2. **URL 输入框可用性改进建议**：中文拼音输入法组合模式会吞键盘注入字母（真实用户手动切英文即可正常输入，功能无损）。建议后续给服务器地址输入框加 `KeyboardType.Uri`，让 IME 自动切英文布局。
3. **测试环境杂音（与 App 无关）**：测试中 USB 瞬断两次（adbd 自动重连）；设置页回收站天数曾被测试点击误改至 45 天后已复位 30 天。
4. 测试用上传配置（`https://upload-test.invalid` + 假令牌）为验证队列机制故意设置，**未触碰任何真实生产服务**；正式联调将切换 Drive 侧 staging。

## 4. 结论

除依赖 Drive 侧 Staging / 设备授权的项（BLOCKED）外，**录制、保存、任务持久化、队列调度、失败重试、状态展示的真机验证全部通过**。APK 侧已具备联调条件：Drive 侧交付三项最小契约（可撤销上传身份、真实上传协议样例、folder/file ID 规则）后，仅需在设置页填入真实地址与令牌即可进入 I01–I14 验收。
